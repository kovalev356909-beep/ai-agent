# ИИ-агент для управления задачами

## Назначение проекта
Этот репозиторий создан для выполнения лабораторных работ по дисциплине «Информационные технологии». 
В рамках курса здесь будет разрабатываться консольный ИИ-агент для управления задачами.

## Описание
Проект представляет собой систему контроля версий Git, настроенную для совместной работы. 
В дальнейшем сюда будет добавлен код приложения, линтеры и тесты. 

## Технологический стек
- Язык: Python (будет использоваться в следующих работах)
- Система контроля версий: Git
- Платформа: GitHub
- Редактор кода: PyCharm
