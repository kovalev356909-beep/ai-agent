# ИИ-агент: Консольный помощник по покупкам «Самокат»

## Назначение проекта
Проект представляет собой консольное приложение (первую версию ИИ-агента), которое имитирует корзину заказов для сервиса «Самокат». В будущем этот проект станет Telegram-ботом для заказа продуктов.

## Технологический стек
- **Язык программирования:** Python 3.14
- **Среда разработки (IDE):** PyCharm
- **Менеджер зависимостей:** pip (управление через интерфейс PyCharm)
- **Сторонние библиотеки:** `ruff` (линтер), `black` (форматтер)
- **Хранение данных:** В оперативной памяти (список `cart` в модуле `logic.py`). При перезапуске данные сбрасываются.
- **Отладчик:** PyCharm Debugger

## Подготовка окружения и запуск
1. Установите Python 3.10 или выше.
2. Установите зависимости (линтер и форматтер): `pip install ruff black`.
3. Запустите приложение из корневой папки проекта командой:
   `python main.py`

## Команды приложения
- `add <название> <цена>` — добавить товар в корзину (пример: `add Молоко 80`).
- `list` — показать текущую корзину и сумму.
- `checkout` — оформить заказ (симуляция).
- `help` — показать справку по командам.
- `exit` — штатное завершение работы приложения.

## Проверка качества кода
- Форматирование: `black main.py logic.py`
- Проверка линтером: `ruff check main.py logic.py`

## Примеры диалога

**Пример 1: Успешное добавление и просмотр**
> Введи команду > add Хлеб 50
> Хлеб (50 руб.) добавлено в корзину.
> Введи команду > add Молоко 80
> Молоко (80 руб.) добавлено в корзину.
> Введи команду > list
> --- Ваша корзина Самокат ---
> 1. Хлеб — 50 руб.
> 2. Молоко — 80 руб.
> Итого к оплате: 130 руб.

**Пример 2: Обработка ошибок ввода**
> Введи команду > add Сыр
> Ошибка: укажи название и цену. Пример: add Молоко 80
> Введи команду > add Сыр abc
> Ошибка: цена должна быть целым числом. Пример: add Молоко 80
> Введи команду > checkout
> Ошибка: корзина пуста, нечего заказывать.x
