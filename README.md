# ИИ-агент: Консольный помощник по заказу продуктов «Самокат»

## Описание проекта
Данный проект представляет собой консольное приложение, разрабатываемое в рамках курса «Информационные технологии». 
Цель проекта — создание **ИИ-агента**, который поможет моей бабушке формировать и заказывать продукты.

## Планируемые возможности
В рамках курса планируется реализовать следующие функции:
1. Добавление выбранного продукта в виртуальную корзину.
2. Просмотр текущего содержимого корзины с ценами.
3. Оформление заказа (симуляция отправки заказа в доставку).

## Технологический стек
- **Язык программирования:** Python
- **Среда разработки:** PyCharm
- **Система контроля версий:** `Git`
- **Платформа для совместной работы:** `GitHub`

## Примеры использования (Ожидаемые результаты)

**Пример 1: Добавление продукта в корзину**
Пользователь вводит команду: `add Молоко 80`
Ожидаемый результат: Приложение выводит сообщение «Молоко (80 руб.) добавлено в корзину. Итого: 80 руб.»

**Пример 2: Просмотр корзины**
Пользователь вводит команду: `list`
Ожидаемый результат: Приложение выводит список добавленных продуктов и общую сумму:
1. Молоко — 80 руб.
Итого к оплате: 80 руб.
